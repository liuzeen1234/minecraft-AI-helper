# 物品分类机（Item Sorter）

> 来源：AstroWorld 指南（guide.astroworldmc.com/how-to-build-item-sorter-minecraft）
> 目标版本：Java 版 1.20.1 / 1.20.4（漏斗/比较器机制在两版本中一致，兼容 Java 与 Bedrock）

基于漏斗的防溢出物品分类机教程。覆盖 41 物品过滤器、比较器机制、通道布局，以及如何处理不可堆叠物品。

物品分类机自动把混合输入流中的物品分到贴有标签的箱子里。标准设计使用漏斗、比较器和红石火把组成紧凑、可平铺的模块。每个模块过滤一种物品类型，需要多少种就并排多少模块，每件物品都会进到正确的箱子。本指南介绍在生存中可靠工作的防溢出设计。

## 为什么建物品分类机？

- 整理刷怪塔产物（骨头、箭、腐肉、护甲等）
- 分类挖矿收获（圆石、铁、金、钻石、红石）
- 管理作物农场产出（小麦、胡萝卜、土豆、甜菜根）
- 可平铺设计，从5种物品扩展到100+种

## 过滤器工作原理（41物品技巧）

每个分类模块使用一个装有特定物品排列的漏斗：

- **槽位1**：41个要过滤的目标物品
- **槽位2-5**：各1个不可堆叠或唯一的填充物（如改名木棍）

总计45个物品在漏斗中。比较器读取这个漏斗，输出信号强度3。当一个匹配物品从上方输入流进入漏斗（数量到46），比较器输出升到信号强度4。更强的信号关闭下方的红石火把，解锁下层漏斗，把多余物品拉进输出箱。

填充物占据槽位2-5防止不想要的物品进入这些槽位（不可堆叠或改名后没有其他物品能和它们堆叠）。只有目标物品能进入槽位1，触发过滤。

## 每个模块的材料

| 物品 | 数量 |
|---|---|
| 漏斗 | 3 |
| 比较器 | 1 |
| 红石火把 | 1 |
| 红石粉 | 2 |
| 箱子（或大箱子） | 1-2 |
| 建筑方块 | 约6 |
| 目标物品 | 41 |
| 填充物（改名木棍） | 4 |

## 分步搭建

### 第1步：建输入线
沿分类系统顶部放一排漏斗形成输入流。物品从一端进入（来自农场、手动输入箱等），沿漏斗链流动。链中每个漏斗位于一个分类模块上方。

```
单个模块侧视图：

 [输入漏斗链] ------> (顶行，物品从左向右流)
 |
 [过滤漏斗] (含41目标 + 4填充物)
 |
 [比较器] --> [红石] --> [火把在方块上]
 |
 [输出漏斗] --> [箱子]
```

### 第2步：放过滤漏斗
在输入链下方放一个朝向输出系统（向下或朝向箱子）的漏斗，这是过滤漏斗。装入41个目标物品和4个填充物（每个占一个槽位）。

### 第3步：加比较器和红石
放置比较器读取过滤漏斗（比较器背面朝向漏斗）。从比较器输出端铺2格红石粉到一块侧面有红石火把的方块上。火把朝下指向输出漏斗。

当过滤漏斗恰好45个物品（静止状态）时，比较器输出信号强度3，不足以穿过2格红石粉到达火把。火把保持开启，锁定输出漏斗（火把从侧面充能时锁定漏斗）。

当一个匹配物品进入（46个）时，信号强度变为4，到达火把。火把关闭，解锁输出漏斗传输一个物品。物品离开后数量回到45，信号减弱，火把重新锁定，系统复位。

### 第4步：放输出漏斗和箱子
输出漏斗位于过滤漏斗下方，被红石火把锁定。解锁时从过滤漏斗拉取物品并推入箱子。在输出漏斗末端放一个大箱子。

### 第5步：平铺设计
沿输入链并排放置相同模块。每个模块分类一种物品。输入链末端放一个"兜底"箱子收集分类器没有过滤的任何物品，防止溢出。

## 溢出保护

41物品设计天然防溢出。即使输出箱完全装满，过滤漏斗最多暂时持有46个物品（41目标+4填充+1输入）。输出满时系统只是停止从输入链拉取，物品继续沿输入链流向下一个模块或兜底箱。

没有填充物的话，随机物品可能填满过滤漏斗的空槽位，最终堵死它。填充物通过永久占据槽位2-5来防止这种情况。

## 处理不可堆叠物品

本设计只对可堆叠物品（堆叠到16或64）有效。不可堆叠物品（护甲、工具、武器、药水）无法用比较器方法分类，因为它们的堆叠数总是1。对不可堆叠物使用溢出设计：让它们穿过所有分类模块到兜底箱，或用所有ay（1.19+）或基于物品消失计时的水流分类的独立系统。

## 常见错误

- **过滤物品数量错误**：用40或42而不是41会改变比较器阈值，破坏过滤。必须正好41。
- **填充物能与输入堆叠**：如果用普通木棍做填充物且输入流里有木棍，填充槽会被填满、过滤失效。用铁砧改名（改名木棍不能和普通木棍堆叠）。
- **比较器模式错误**：比较器必须在默认模式（非作差模式）。如果比较器前端的火把亮着，就是作差模式，右键切换回去。
- **漏斗朝向错误**：过滤漏斗必须朝向输出系统。朝向错了，过滤物品会回到输入链。
- **没有兜底箱**：不匹配任何过滤器的物品会沿输入链继续走。末端没有箱子就会堵死整个系统。

## 常见问题

**分类机每秒能处理多少物品？** 每个漏斗每4游戏刻（0.4秒）传输1个物品。单条输入链约处理2.5物品/秒。要更高吞吐就并行跑多条输入链。

**基岩版能用吗？** 能。比较器和漏斗机制在基岩版一致，设计无需修改。

**能分类堆叠到16的物品（如末影珍珠）吗？** 能，但过滤数量要变。16堆叠物品在槽位1放10个目标物品，槽位2-5照常放填充物，比较器阈值相应调整。
