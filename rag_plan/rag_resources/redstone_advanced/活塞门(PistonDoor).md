# 活塞门（Piston Door）

> 来源：AstroWorld 指南（guide.astroworldmc.com/how-to-build-piston-door-minecraft）
> 目标版本：Java 版 1.20.1 / 1.20.4（指南兼容 Java 与 Bedrock）

分步活塞门教程，覆盖 2×2 和 3×3 平贴（flush）设计，包括红石布线图、方块放置顺序和常见布线错误。

活塞门是最有成就感的红石建筑之一。它们外观干净、能平整地藏进墙里，可以用按钮、压力板或隐藏输入触发。本指南覆盖 2×2 平贴活塞门（入门友好）和 3×3 平贴活塞门（进阶），各带完整布线方案。

## 什么是平贴活塞门？

平贴活塞门关闭时完全与墙面平齐，正面看不到任何活塞或红石。激活时方块缩回墙内露出门洞。"平贴"意味着门方块与周围墙面齐平，没有内凹边框或外露活塞。

## 2×2 平贴活塞门

### 材料

| 物品 | 数量 |
|---|---|
| 黏性活塞 | 4 |
| 红石粉 | 12-16 |
| 红石中继器 | 2-4 |
| 红石火把 | 2 |
| 门面建筑方块 | 4 |
| 布线建筑方块 | 约20 |
| 按钮或拉杆 | 1-2 |

### 第1步：放门方块和活塞
门洞是墙上的2宽2高缺口。墙后放4个黏性活塞：左侧2个朝右，右侧2个朝左。每个活塞把一个门方块推进门洞。活塞伸出时方块合拢关门；缩回时方块拉回墙内开门。

```
正视图（门关闭）：

 WWWWWWWW
 WW[D][D]WW
 WW[D][D]WW
 WWWWWWWW

D = 门方块（由背后活塞推动）
W = 墙方块
```

### 第2步：给底部活塞布线
从按钮位置铺红石粉到每个活塞背后。用红石火把做反相器：默认状态应为"活塞伸出"（门关闭）。按下按钮时，信号经火把反相，切断活塞供电，活塞缩回开门。

在每个底部活塞背后的方块上放一个红石火把。从按钮在方块上铺红石粉到支撑火把的方块。按钮按下时火把关闭、活塞缩回、门打开。

### 第3步：给顶部活塞布线
顶部活塞需要和底部相同的信号。用中继器或火把塔把红石往上引一格。最简单的方法：在每个红石火把上方放一个方块，方块被充能后，从它铺红石到顶部活塞。这样火把塔同时给每列的两个活塞供电。

### 第4步：加时序
按钮操作的门（按下自动开、脉冲结束后自动关）可以利用按钮脉冲长度配合火把反相器自然工作：按下按钮门开，脉冲结束门关。拉杆（切换）则门在拉杆拨动期间保持打开。

## 3×3 平贴活塞门

### 材料

| 物品 | 数量 |
|---|---|
| 黏性活塞 | 12-14 |
| 红石粉 | 30-40 |
| 红石中继器 | 6-10 |
| 红石火把 | 4-6 |
| 门面建筑方块 | 9 |
| 布线建筑方块 | 约50 |
| 按钮或拉杆 | 1-2 |

### 3×3 工作原理

3×3 门复杂得多，因为中央一列方块必须按顺序缩回。底行先缩回（由下方活塞下拉），然后两侧缩回（由左右活塞侧拉），最后顶行缩回（由上方活塞上拉）。时序必须精确：每阶段用中继器把信号延迟1-2刻。

```
缩回顺序：

第1步：底行下拉       第2步：侧列侧拉       第3步：顶行上拉、中央收尾
 [D][D][D]             [_][D][_]             [_][_][_]
 [D][D][D] -->         [_][D][_] -->         [_][_][_] (门完全打开)
 [D][D][D]             [_][_][_]             [_][_][_]
```

### 关键布线原则

每个活塞组（底部、两侧、顶部/中央）需要独立的信号延迟：

- 底部活塞：立即触发（输入0刻延迟）
- 侧活塞：2刻后触发（1个中继器设2刻）
- 顶部和中央活塞：4刻后触发（2个中继器或1个设4刻）

关门时顺序反过来：顶部/中央先、两侧次之、底部最后。这需要为开和关两个序列分别布线，通常用 T 触发器（切换电路）连接按钮。

## 常见错误

- **黏性活塞朝向错误**：布线前检查每个活塞的朝向。朝向错会毁掉整扇门。
- **3×3 时序问题**：活塞触发顺序错会导致方块碰撞或遗留。先不装门方块，观察活塞伸缩来测试顺序。
- **红石粉给相邻活塞供电**：信号会穿过方块泄漏到无关活塞。用台阶、玻璃或空气间隙隔离布线通道。
- **用了普通活塞而不是黏性**：普通活塞只推不拉。平贴门的每个活塞都必须是黏性活塞。
- **准连接问题（Java）**：Java 版活塞可被其上方方块充能（准连接/"BUD"行为），导致活塞意外触发。布线时要考虑这一点，或刻意利用它。

## 常见问题

**能做比 3×3 更大的门吗？** 可以。4×4 和 5×5 门可行但布线时序复杂得多。3×3 是多数生存建筑的实际上限。更大的门常见于创造/红石展示世界。

**服务器上能用吗？** 能。活塞门在服务器正常工作。但卡顿会导致中继器时序问题。服务器 TPS 高延迟时，把中继器延迟加1刻补偿。

**怎么隐藏布线？** 把布线建在墙后、地下或假墙里。门面是唯一可见部分。用墙体本身的方块隐藏门上方和下方的红石。
