# 中世纪小屋（Medieval House）

> 来源：AstroWorld 指南（guide.astroworldmc.com/how-to-build-a-medieval-house）
> 目标版本：Java 版 1.20.1 / 1.20.4（指南同时兼容 Java 与 Bedrock）

一座都铎（Tudor）风格建筑：石质基座、**深色橡木框架**配白色灰泥填充、交叉斜撑和陡峭的高屋顶。

## 五步搭建

1. **铺石质基座**：用圆石或石砖搭建房子的地基。
2. **立木框架**：用深色橡木（dark oak）竖角柱、横梁，勾勒出墙体轮廓。
3. **灰泥填充**：在木框架之间的面板里填入白色灰泥方块（白色混凝土、闪长岩或骨块）。
4. **加交叉斜撑**：在部分面板中放置对角深色橡木斜撑，营造都铎风。
5. **盖陡峭屋顶**：顶部用深色楼梯或深板岩瓦盖高而陡的坡屋顶，并加烟囱。

## 快速问答

**怎么建中世纪小屋？** 先铺圆石基座，再用深色橡木框架立角柱和横梁，面板之间填白色灰泥，加对角交叉斜撑，最后盖陡峭坡屋顶。小窗户和烟囱收尾。

**用什么方块？** 基座和烟囱用圆石或石砖；木框架用深色橡木原木和木板；灰泥用白色混凝土、闪长岩或骨块；陡屋顶用深色楼梯或深板岩瓦；小窗户用玻璃板。

**木框架的技巧是什么？** 先用深色橡木的柱和梁勾勒墙体，再在间隙填入白色灰泥，部分面板加对角斜撑。深色框架映衬白色填充正是中世纪感的来源。

**为什么陡屋顶重要？** 中世纪房屋的屋顶高而陡，常常和墙一样高。缓坡屋顶看起来偏现代，所以山墙要陡、略向外挑檐，才有旧世界的轮廓。

**怎么让它看起来有年头、有人住？** 用苔石混合，混用两三种木色调，让木框架略微不规整，二层比一层向外凸出一格（jetty）。透过小窗户的暖色室内光最能衬托年代感。

**基岩版一样吗？** 一样。原木、木板、灰泥方块、楼梯和玻璃板在 Java 和基岩版行为一致，同样的都铎木框架小屋在两个版本可原样建造。
