# 新手小屋（Starter House）

> 来源：AstroWorld 指南（guide.astroworldmc.com/how-to-build-a-starter-house）
> 目标版本：Java 版 1.20.1 / 1.20.4（指南同时兼容 Java 与 Bedrock）

一个快速的第一夜庇护所，使用**木头和圆石**：铺地基、立墙、盖屋顶，天黑前点灯。

## 材料清单

| 材料 | 数量 | 用途 |
|---|---|---|
| 橡木木板（Oak Planks） | 158 | 墙壁 + 屋顶（第4~8层） |
| 圆石（Cobblestone） | 48 | 地基 + 墙壁（第1~3层） |
| 橡木原木（Oak Log） | 16 | 地基 + 墙壁角柱（第1~4层） |
| 玻璃（Glass） | 4 | 窗户（第2层） |
| 橡木门（Oak Door） | 2 | 门（第1~2层） |

总计：228个方块 · 尺寸 7×6×8。制作提示：1个橡木原木可合成4个木板；圆石用任意镐挖掘石头获得；玻璃由沙子熔炼；门由6个橡木木板合成（一次出3个）。

## 搭建步骤（分层）

1. **地基**：清理一块平地，用圆石铺一个约7×7的地基。
2. **墙体**：用橡木木板砌约3格高的墙，四角用橡木原木做角柱。
3. **门窗**：留出门洞和窗洞，安装橡木门与玻璃。
4. **屋顶**：用橡木木板做一个简单的人字坡（gable）屋顶。
5. **内饰与照明**：屋内放床、工作台、熔炉、箱子；用火把照亮屋内和屋外，确保没有暗处。

## 快速问答

**怎么建新手小屋？** 清理一块平地，铺约7×7的圆石地基，用橡木木板砌约3格高的墙、四角用原木做角柱，留出门和窗，再用木板盖人字坡屋顶。装上门口、插上火把，就是安全的第一夜基地。

**需要哪些方块？** 第一天就能获得的必需品：橡木原木（合成木板）、挖矿得到的圆石、一扇门、窗户玻璃和火把。屋内放工作台、熔炉、箱子和床。

**小屋多大合适？** 第一夜尽量小，内部约6×6或7×7，建造快、容易照明。站稳脚跟后再拆墙扩建。

**如何防止怪物在屋内或周围生成？** 用火把照亮内部和屋外周边，确保没有黑暗处；用方块或门封住所有缺口。建在山上或靠悬崖也能减少怪物可到达的开阔面。

**怎么让新手小屋好看？** 四角用橡木原木做框架，用一两扇窗户打破墙体，用楼梯或深色木材（如云杉）做坡屋顶。小路和栅栏等小细节能让小屋更像家。

**Java 和基岩版通用吗？** 通用。放置方块、门、玻璃和火把在两个版本行为一致，同样的设计步骤适用。

## 第一夜前建完的时间预算

MC 一天持续10现实分钟，黄昏大约从第7分钟开始。时间预算：几分钟砍树、一分钟挖圆石，其余时间用来建造。本小屋228个方块，其中158个木板来自16根原木（约4棵树）。

**天黑了先跳过什么？** 窗户和屋顶可以留到早上。一个封顶、有门和两根火把的密封盒子就能保命；玻璃和人字坡不是必需品。

## 第一夜小屋要满足什么

- **生存，仅此而已**：四堵墙、屋顶、门、足够的火把让每格地板都不暗。
- **建在明天还想用的地方**：靠近水源、树木和可采矿点；靠悬崖可以少建一堵墙、少一个怪物来向。
- **预留要拆的墙**：把后墙留白、后方地面留平，第二天扩建第二间房时直接接上。
- **内饰顺序最省时间**：先放床（设定重生点），再放工作台和熔炉（整晚要用），最后放箱子（等确定哪堵墙不拆再放，避免满箱搬运）。
