# 城堡（Castle）

> 来源：AstroWorld 指南（guide.astroworldmc.com/how-to-build-a-castle）
> 目标版本：Java 版 1.20.1 / 1.20.4（指南同时兼容 Java 与 Bedrock）

**护城墙**、四角塔楼、高耸的中央**主楼（keep）**和城门楼（gatehouse），顶部以雉堞（城齿）和旗帜收尾。

## 五步搭建

1. **勾画占地**：先在地面粗略画出整座城堡的完整轮廓。
2. **建护城墙**：沿占地轮廓建造四周的围墙。
3. **加角塔**：在每个角上和城门旁各立一座塔楼。
4. **建主楼与城门楼**：中央建高塔主楼，入口上方建城门楼。
5. **雉堞与细节**：加城齿、旗帜、照明和内部庭院。

## 所需材料

- **石砖**：城墙与主楼。
- **圆石**：塔楼。
- **木材**：城门与装饰线脚。
- **火把与旗帜**：顶部照明与装饰。

## 快速问答

**怎么建城堡？** 先勾画占地，绕四周建护城墙，四角各放一座塔。中央加一座更高的主楼，入口处建带主门的城门楼，然后在顶部加城齿、挂旗帜、点灯。先建城墙和塔，再填庭院。

**城堡由哪些部分组成？** 环绕周边的护城墙、四角和城门处的塔楼、作为中央高耸要塞的主楼、入口上方的城门楼，以及内部庭院。加上城齿、箭孔、护城河和旗帜就是完整的样子。

**怎么避免城堡看起来像方块堆？** 让塔楼高低宽窄不一，墙体底部加宽或做斜脚（battered foot），加水平装饰带（string-course）和挑出的城齿，用第二种材料打破纯石头的单调。更高、细节更丰富的主楼给整体一个视觉焦点。

**城堡该多大？** 比你想的大，因为城墙和塔楼很占空间。小型城堡的占地至少从30×30起步，先把整个轮廓勾出来，避免主楼和庭院没地方放。

**用什么方块？** 城墙和塔楼用石砖、圆石和安山岩，混入苔石和裂纹变体体现年代感，深色木材做门和木结构，彩色羊毛或混凝土做旗帜。深板岩能做出更暗的堡垒风。

**基岩版一样吗？** 一样。城墙、塔楼、城齿、城门和旗帜在两个版本行为一致，同样的布局和建造顺序都适用。
