# 巨型木桶酒馆（Ultimate Player Favorite Giant Barrel Tavern Survival Base）

一座独立的巨型木桶造型酒馆生存基地图纸（Sponge .schem），适合人气舒适幻想酒馆、独特生存小屋、酿酒基地或 WorldEdit 就绪建筑。

## 外观特征

- 巨大木桶造型：深色橡木板条（staves）、磨制黑石金属箍、圆形端盖
- 透明双开门入口、圆形玻璃窗、带百叶的侧窗
- 花箱、酒馆招牌、可工作的水龙头细节
- 石质摇篮式支架、露台甲板、户外餐桌、花园小径、池塘、树木、暖色灯笼照明

## 完整内饰（带家具）

- 完整酒馆大厅、吧台
- 厨房与冶炼站、酿造角、壁炉、餐桌
- 储物墙、合成与锻造工坊
- 木桶、箱子、卧室、附魔阁楼
- 地图休息室、末影箱、屋顶农场
- 楼梯、梯子、地毯，以及开放的生存友好动线

面向 Java 生存服、SMP 城镇、中世纪村庄、幻想酒馆、新手基地升级、角色扮演服、FAWE/WorldEdit 和公共图纸库设计。
