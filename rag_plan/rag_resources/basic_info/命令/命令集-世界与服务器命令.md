# 命令集-世界与服务器命令

> 目标版本：Java 版 1.20.4。

## 时间与天气

### `/time`
- 语法：`/time <set|add|query> <时间|day|noon|night|midnight|...>`。
- 时间值：`day`=1000、`noon`=6000、`night`=13000、`midnight`=18000、`sunrise`=23000、`sunset`=12000。
- 示例：`/time set day`、`/time set 6000`、`/time add 1000`、`/time query daytime`。
- 权限：2。

### `/weather`
- 语法：`/weather <clear|rain|thunder> [持续时间(秒)]`。
- 示例：`/weather thunder 100`。
- 权限：2。

### `/toggledownfall`
- 语法：`/toggledownfall`；切换晴天/降雨（旧命令，推荐 `/weather`）。权限 2。

### `/seed`
- 语法：`/seed`；显示世界种子（服务器需权限 2，单机可用）。权限：2（服务器）。

## 游戏规则

### `/gamerule`
- 语法：`/gamerule <规则> [值]`。
- 常用规则：
  - `doDaylightCycle`（昼夜循环）、`doWeatherCycle`（天气循环）
  - `doMobSpawning`、`doMobLoot`、`mobGriefing`（生物破坏方块）
  - `doTileDrops`（方块掉落）、`doFireTick`（火焰蔓延）
  - `keepInventory`（死亡保留物品）、`naturalRegeneration`（自然回血）
  - `commandBlockOutput`、`sendCommandFeedback`
  - `randomTickSpeed`（默认 3，见刻.md）
  - `playersSleepingPercentage`（跳过夜晚所需玩家比例）
  - `doLimitedCrafting`（仅限已解锁配方）
  - `doVillagerTrading`、`doTraderSpawning`
  - `doPatrolSpawning`、`doInsomnia`（幻翼）、`doWardenSpawning`
  - `fallDamage`、`fireDamage`、`freezeDamage`、`drowningDamage`（1.20.2+）
  - `tntExplosionDropDecay`、`mobExplosionDropDecay`、`lavaSourceConversion`（1.19.3+）、`snowAccumulationHeight`（1.19.3+）、`waterSourceConversion`
  - `announceAdvancements`、`forgiveDeadPlayers`、`universalAnger`
  - `spectatorsGenerateChunks`、`spawnRadius`
  - `maxCommandChainLength`、`maxEntityCramming`、`logAdminCommands`
- 示例：`/gamerule keepInventory true`、`/gamerule randomTickSpeed 0`。
- 权限：2。

## 世界边界与出生点

### `/worldborder`
- 语法：
  - `/worldborder add <距离>`（扩张）、`/worldborder set <距离> [时间]`（设置）
  - `/worldborder center <坐标>`、`/worldborder damage amount|buffer <值>`
  - `/worldborder warning time|distance <值>`、`/worldborder get`
- 示例：`/worldborder set 1000 30`（30 秒内扩张到 1000）。
- 权限：2。

### `/forceload`
- 语法：`/forceload add|remove|query <坐标> [坐标]`；强制加载区块（保持刻运行与实体活动）。
- 示例：`/forceload add 0 0 10 10`。
- 权限：2。

### `/locate`
- 语法：`/locate structure <结构ID>`、`/locate biome <生物群系ID>`、`/locate place <poi>`。
- 结构示例：`/locate structure minecraft:ancient_city`、`/locate structure minecraft:stronghold`。
- 生物群系示例：`/locate biome minecraft:cherry_grove`。
- 返回最近坐标；权限 2。

## 区块与地图

### `/datapack`
- 语法：`/datapack <enable|disable|list> [名称]`。
- 示例：`/datapack enable "file:我的数据包"`、`/datapack list available`。
- 权限：3。

### `/reload`
- 语法：`/reload`；重载所有数据包（进度、函数、配方等）。权限 3（wiki 标注 4，多数服务器按 3 配置）。

### `/debug`
- 语法：`/debug start|stop|function <函数ID>`；记录刻性能调试数据（生成 .nbt 报告）。
- 权限：4。

### `/perf`
- 语法：`/perf start|stop`；创建性能分析报告。权限 4。

### `/jfr`
- 语法：`/jfr start|stop`；Java Flight Recorder 分析。权限 4。

### `/tick`
- 语法：`/tick query|rate <数值>|freeze|step <次数>|step stop|unfreeze`。
- 说明：1.20.3+ 新增；控制刻运行与性能测量；详见 `游戏机制/刻的应用与时序速查.md`。
- 权限：3。

### `/wsserver`
- 语法：`/wsserver <地址>`；连接 WebSocket 调试服务器（对数据包开发）。权限 4。

## 服务器管理

### `/op` 与 `/deop`
- 语法：`/op <玩家>`、`/deop <玩家>`；授予/移除操作员权限。权限 3。

### `/ban`、`/ban-ip`、`/banlist`、`/pardon`、`/pardon-ip`
- 语法：`/ban <玩家> [原因]`、`/ban-ip <IP> [原因]`、`/banlist [ips]`、`/pardon <玩家>`、`/pardon-ip <IP>`。
- 封禁玩家/IP 与管理封禁列表。权限 3。

### `/whitelist`
- 语法：`/whitelist <on|off|list|add|remove|reload>`。
- 示例：`/whitelist add Steve`、`/whitelist on`。
- 权限：3。

### `/kick`
- 语法：`/kick <玩家> [原因]`；踢出玩家。权限 3。

### `/setidletimeout`
- 语法：`/setidletimeout <分钟>`；设置挂机自动踢出时间（0 禁用）。权限 3。

### `/publish`
- 语法：`/publish [端口]`；将单机世界开放为局域网服务器。权限 4（单机）。

### `/save-all`、`/save-off`、`/save-on`
- `/save-all [flush]`：保存世界；`/save-off` 暂停自动保存；`/save-on` 恢复。权限 4。

### `/stop`
- 语法：`/stop`；关闭服务器并保存。权限 4。

### `/list`
- 语法：`/list [uuids]`；列出在线玩家。权限 0（返回给自己）。

### `/help`（/?）
- 语法：`/help [命令]`；显示命令帮助。权限 0。

### `/difficulty`
- 语法：`/difficulty <peaceful|easy|normal|hard>`（或 0/1/2/3）。
- 示例：`/difficulty hard`。
- 权限：2。
