# 命令集-数据与执行命令

> 目标版本：Java 版 1.20.4。

## `/execute`（条件执行，最强大命令）

### 基本语法
- `/execute <子命令>... run <命令>`：按子命令依次变换"执行者、位置、朝向"后运行命令。
- 子命令链可任意组合；条件不满足时整条命令不执行（除非 `if/unless` 失败）。

### 核心子命令
| 子命令 | 作用 | 示例 |
|---|---|---|
| `as <实体>` | 把执行者设为实体 | `as @e[type=zombie]` |
| `at <实体>` | 把位置设为实体位置 | `at @s` |
| `positioned <坐标>` | 设置位置 | `positioned 0 64 0` |
| `positioned as <实体>` | 位置设为实体 | `positioned as @p` |
| `positioned over <高度>` | 1.20.3+，取上方某高度的方块位置 | `positioned over 64` |
| `anchored <eyes|feet>` | 以眼睛/脚部为锚点 | `anchored eyes` |
| `facing <坐标>` / `facing entity <实体>` | 设置朝向 | `facing 0 64 0` |
| `rotated <角度>` / `rotated as <实体>` | 设置旋转角 | `rotated 0 90` |
| `align <轴>` | 坐标取整（x/y/z/xyz） | `align xz` |
| `in <维度>` | 切换维度（overworld/the_nether/the_end） | `in the_nether` |
| `on <关系>` | 以关联实体执行（attacker/owner/vehicle/...） | `on vehicle` |
| `if <条件>` / `unless <条件>` | 条件判断 | `if entity @e[type=creeper]` |
| `store <存储>` | 把命令结果存为数值 | `store result score @s obj` |
| `summon <实体> <坐标>` | 1.20.2+，直接生成实体 | `summon zombie ~ ~1 ~` |

### 条件类型（if/unless）
- `if entity <实体>`：实体存在。
- `if block <坐标> <方块>`：方块匹配（支持状态 `[lit=true]` 与标签 `#minecraft:...`）。
- `if blocks <区域> <位置> <模式>`：区域方块匹配（all/masked）。
- `if score <目标> <目标> <操作> <源>`：记分板数值比较（matches `<范围>` 或 `<比较>`）。
- `if data block|entity|storage <目标> <路径>`：NBT 数据存在。
- `if predicate <谓词>`：数据包谓词判定。
- `if loaded <坐标>` / `if biome <坐标>`（1.19.4+）：区块加载/生物群系判定。

### store 类型
- `store result score <实体> <记分板>`：存整数结果。
- `store result|success bossbar <id> <value|max>`：存入 Boss 血条。
- `store result|success block <坐标> <路径> <类型> <倍数>`：写入方块 NBT。
- `store result|success entity <实体> <路径> <类型> <倍数>`：写入实体 NBT。
- `store result|success storage <存储id> <路径> <类型> <倍数>`：写入存储。
- 类型：byte/short/int/long/float/double。

### 典型用法
- `execute as @a at @s run say hi`（所有玩家说 hi）。
- `execute if entity @a[distance=..10] run say 有玩家在附近`。
- `execute store result score @s x run data get entity @s Pos[0]`（把 X 坐标存入记分板）。
- `execute at @e[type=zombie] run summon lightning_bolt ~ ~ ~`（每只僵尸处召雷）。
- `execute as @a[nbt={SelectedItem:{id:"minecraft:stick"}}] run effect give @s speed 5`（手持木棍者获得速度）。

## `/data`（NBT 数据读写）

- 语法：
  - `/data get block|entity|storage <目标> [路径] [倍数]`
  - `/data merge block|entity|storage <目标> <NBT>`
  - `/data remove block|entity|storage <目标> <路径>`
  - `/data modify block|entity|storage <目标> <路径> <操作>`
- 示例：`/data get entity @e[type=zombie,limit=1] Health`、`/data merge block ~ ~-1 ~ {CustomName:'"改名"'}`。
- 注意：`/data` 修改不触发方块更新（侦测器侦测不到方块状态变化以外的 NBT 变更）。

## `/scoreboard`（记分板）

### 目标（Objectives）
- `/scoreboard objectives add <名称> <判据> [显示名]`：创建计分项。
- 判据（criteria）：`dummy`（手动）、`health`、`kills`、`deaths`、`totalKillCount`、`playerKillCount`、`minecraft.used:<物品>`、`minecraft.mined:<方块>`、`minecraft.crafted:<物品>`、`minecraft.broken:<物品>`、`minecraft.killed:<实体>`、`minecraft.killed_by:<实体>`、`minecraft.custom:<统计>`（如 `minecraft.custom:minecraft.walk_one_cm`）、`teamkill.<颜色>`、`trigger` 等。
- `/scoreboard objectives remove <名称>`、`list`、`setdisplay <栏位> <名称>`（栏位：list/sidebar/belowName）。
- 1.20.3+ 支持记分板显示名（`setdisplay` 可带颜色等文本组件）。

### 玩家分数操作
- `/scoreboard players add|remove|set|reset|get <玩家> <计分项> <数量>`
- `/scoreboard players operation <目标> <计分项> <操作> <源> <计分项>`（操作：+=、-=、*=、/=、%=、=、><、<、>）
- 示例：`/scoreboard players set @p coins 100`、`/scoreboard players operation @a total += @s coins`。

### 标签与列表
- `/scoreboard players list [玩家]`、`/scoreboard objectives list`、`/scoreboard players tag`（已被独立 `/tag` 取代，1.13+ 用 /tag）。

## `/tag`

- 语法：`/tag <实体> add|remove|list <标签>`。
- 示例：`/tag @e[type=zombie] add boss`、`/tag @s remove temp`。
- 权限：2。

## `/team`

- 语法：`/team add <名称> [显示名]`、`/team remove|empty|join|leave|modify|list <...>`。
- `join` 示例：`/team join red @p`；`modify`：颜色、友好度、碰撞规则、死亡消息、称号等。
- 权限：2。

## `/bossbar`

- 语法：
  - `/bossbar add <id> <显示名>`（显示名为 JSON）
  - `/bossbar set <id> <max|value|name|color|style|visible|players> <...>`
  - `/bossbar remove <id>`
- 示例：`/bossbar add boss_health {"text":"Boss"}`、`/bossbar set boss_health players @a`。
- 权限：2。

## `/damage`

- 语法：`/damage <实体> <伤害量> [<伤害类型> [at|by <来源>]]`。
- 伤害类型：`minecraft:generic`、`minecraft:explosion`、`minecraft:fire`、`minecraft:fall`、`minecraft:wither`、`minecraft:drown` 等。
- 示例：`/damage @e[type=pig] 5 minecraft:lightning_bolt`。
- 权限：2。

## `/function` 与 `/schedule`

- `/function <函数ID>`：执行数据包中的函数（`namespace:path` 或 `#标签`）。
- `/function <函数ID> {参数}`：1.20.2+ 宏调用（函数参数）。
- `/schedule function <函数ID> <延迟> [append|replace]`：延迟执行（游戏刻）；`/schedule clear <函数ID>` 取消。
- 示例：`/schedule function mypack:tick 20`（1 秒后执行）。
- 权限：2。

## `/return`（1.20.2+）

- 语法：`/return <run <命令>|fail|value <值>>`；在函数内返回（中断函数执行并可返回值给 execute store）。
- 示例：`/return value 1`。
- 权限：2。

## `/trigger`

- 语法：`/trigger <计分项> [add|set] <值>`；让玩家通过命令触发记分板（需 `scoreboard objectives add x trigger`）。
- 用于冒险地图玩家交互。权限：0（玩家可用）。

## `/fill`、`/clone`、`/setblock`、`/place`

### `/setblock`
- 语法：`/setblock <坐标> <方块> [destroy|keep|replace]`。
- 示例：`/setblock ~ ~1 ~ minecraft:oak_log[axis=x]`、`/setblock ~ ~ ~ minecraft:air destroy`。
- 权限：2。

### `/fill`
- 语法：`/fill <起点> <终点> <方块> [replace|destroy|keep|outline|hollow] [过滤]`。
- 示例：`/fill 0 60 0 10 70 10 minecraft:stone`、`/fill ~-5 ~-1 ~-5 ~5 ~-1 ~5 minecraft:water`、`/fill x1 y1 z1 x2 y2 z2 minecraft:oak_planks replace minecraft:dirt`。
- 数量上限：`/fill` 默认 32768 方块（超出报错）。权限 2。

### `/clone`
- 语法：`/clone <源起点> <源终点> <目标> [replace|masked|filtered] [force|move|normal]`。
- 示例：`/clone 0 60 0 10 70 10 20 60 20`。
- 权限：2。

### `/place`
- 语法：`/place <feature|jigsaw|structure|template> <类型> [坐标]`。
- 示例：`/place structure minecraft:village_plains ~ ~ ~`、`/place feature minecraft:ruined_portal`。
- 权限：2。1.19.4+ 取代 `/structure`。

## `/fillbiome`

- 语法：`/fillbiome <起点> <终点> <生物群系>`。
- 示例：`/fillbiome 0 0 0 100 10 100 minecraft:desert`。
- 权限：2。

## `/loot`

- 语法：
  - `/loot spawn <坐标> <来源>`（生成掉落物）
  - `/loot give <玩家> <来源>`
  - `/loot insert <容器> <来源>`、`/loot replace <实体> <栏位> <来源>`
- 来源：`kill <实体>`、`mine <方块>`、`loot <战利品表>`、`fish`。
- 示例：`/loot spawn ~ ~ ~ loot minecraft:chests/simple_dungeon`、`/loot give @p kill @e[type=creeper,limit=1]`。
- 权限：2。

## `/spreadplayers`

- 语法：`/spreadplayers <中心坐标> <最小距离> <最大距离> <respectTeams> <实体>`。
- 示例：`/spreadplayers 0 0 5 50 true @a`。
- 权限：2。

## `/attribute`

- 语法：`/attribute <实体> <属性> <get|base get|base set|modifier add|modifier remove|modifier value get> <...>`。
- 属性：`minecraft:generic.max_health`、`minecraft:generic.movement_speed`、`minecraft:generic.attack_damage`、`minecraft:generic.armor`、`minecraft:generic.knockback_resistance`、`minecraft:generic.follow_range`、`minecraft:generic.flying_speed`、`minecraft:generic.luck`、`minecraft:generic.attack_knockback`、`minecraft:generic.attack_speed`、`minecraft:player.block_break_speed`、`minecraft:zombie.spawn_reinforcements` 等。
- 示例：`/attribute @e[type=zombie,limit=1] minecraft:generic.max_health set 50`。
- 权限：2。
