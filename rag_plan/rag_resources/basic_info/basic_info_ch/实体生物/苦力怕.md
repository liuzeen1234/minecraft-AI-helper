# 苦力怕

**苦力怕（Creeper）** 是常见的敌对生物，会悄无声息地接近玩家，距离目标 3 格内开始爆炸倒计时。是火药的主要来源，也是获得大多数音乐唱片的途径之一。

## 基础属性

| 属性 | 值 |
|---|---|
| 生命值 | 20（10 心） |
| 类型 | 敌对生物 |
| 尺寸（Java 版） | 高 1.7 格，宽 0.6 格 |
| 尺寸（基岩版） | 高 1.8 格，宽 0.6 格 |
| 生成条件 | 主世界亮度等级为 0 的可刷怪方块上（蘑菇岛、深暗之域除外） |
| 爆炸伤害（普通，100% 接触率） | 简单 22.5 / 普通 43 / 困难 64.5 |
| 爆炸伤害（闪电变种，100% 接触率） | 简单 43.5 / 普通 85 / 困难 127.5 |

## 生成与掉落

- 自然生成于主世界亮度为 0 的固体方块上；Java 版最多以 4 个一组生成，基岩版单独生成。
- 掉落物：
  - 0–2 个火药（每级抢夺魔咒 +1，抢夺 III 最多 5 个）。
  - 被骷髅/凋灵骷髅（仅 Java 版）/流浪者杀死时，掉落一张音乐唱片（13、cat、blocks、chirp、far、mall、mellohi、stal、strad、ward、11 或 wait 之一）。
  - 被闪电苦力怕杀死时掉落苦力怕头。
  - 被玩家或驯服的狼杀死时掉落经验值 5。

## 行为机制

- 追击范围：水平 16 格（±5%），垂直 ±4 格内的玩家。Java 版中玩家佩戴苦力怕头时探测范围减半（8 格）。
- 若被其他生物伤害，会忽略玩家转而追逐该生物。
- 基岩版：玩家隐身且未穿任何盔甲时，无论距离多近苦力怕都不会发现玩家。
- 无空闲音效和脚步声，追击过程无声，难以察觉。

### 爆炸倒计时

- 距离目标 3 格内时开始 30 游戏刻（1.5 秒）爆炸倒计时，期间发出嘶嘶声、身体膨胀并闪烁。
- Java 版：倒计时期间寻路停止（不移动）；基岩版：倒计时期间仍会继续追击。
- 若倒计时结束时与目标距离超过 7 格（如被击退或目标远离），则不会爆炸。
  - Java 版：倒计时会在 30 游戏刻内倒放回落到 0，然后恢复移动。
  - 基岩版：倒计时立即重置为 0。
- 有目标的苦力怕能接受的摔落高度为 `3 + 剩余生命值 - 1`，只要不致命就会主动跳下高处。
- 受到摔落伤害后，爆炸倒计时立即增加 `摔落伤害 × 1.5`（至多设为 25）。
- 可用打火石或火焰弹（仅 Java 版）直接激活，进入不可取消的 1.5 秒倒计时。
- 苦力怕能爬梯子和藤蔓，但不会主动这样做。
- 与猫/豹猫距离 ≤ 6 格且未开始爆炸时，会沿直线逃离直到 16 格外；已开始爆炸的苦力怕不会因猫而逃跑，除非玩家离开爆炸半径。
- 苦力怕爆炸威力为 3。Java 版中带有状态效果的苦力怕爆炸后会在原地生成对应效果的区域效果云。
- 驯服的狼、铁傀儡、僵尸疣猪兽不会主动攻击苦力怕；但雪傀儡、监守者、名为 Johnny 的卫道士、凋灵，以及与其不同队伍的潜影贝仍会攻击苦力怕；山羊会随机冲撞苦力怕（不触发其爆炸）。

## 闪电苦力怕（Charged Creeper）

普通苦力怕周围 4 格内被闪电击中（自然、引雷魔咒三叉戟、避雷针引雷或 `/summon`）会转化为闪电苦力怕，外观带蓝色电弧。

- 爆炸威力为 6（TNT 的 1.5 倍，普通苦力怕的 2 倍）。
- 实体数据 `powered` 为 `1`（普通苦力怕为 `0`）。
- 炸死苦力怕、骷髅、凋灵骷髅、僵尸、猪灵时，这些生物会掉落对应头颅；Java 版中同时炸死多只时只有一只掉头。闪电苦力怕自身不会掉落头颅；玩家和末影龙不会掉落头颅。
- 生成命令：
  - Java 版：`/summon creeper ~ ~ ~ {powered:1}`
  - 基岩版：`/summon creeper ~ ~ ~ minecraft:become_charged`

## 数据值

| 名称 | 命名空间 ID |
|---|---|
| 苦力怕 | `creeper` |

常用实体数据（Java 版）：

- `ExplosionRadius`：爆炸威力，默认 3。
- `Fuse`：从引燃到爆炸的时间（默认 30，单位游戏刻）。
- `ignited`：是否被玩家用物品点燃。
- `powered`：是否为闪电苦力怕（可能不存在，等价于 `0`）。
