# 被动生物

> 目标版本：Java 版 1.20.4。被动生物不会主动攻击玩家。生命值为 Java 版数值。

## 家畜类

### 牛（Cow）`cow`
- 样子：棕白花斑牛，成年高约 1.4 格。
- 生命 10；生成于草原/森林等亮度≥9 的草地上。
- 行为：缓慢游荡；被小麦吸引；可繁殖（小麦）；被闪电击中变蘑菇牛。
- 掉落：生牛肉 1–3、皮革 0–2；被火烧死掉熟牛肉。
- 用途：牛奶（桶右键）、繁殖、皮革。

### 蘑菇牛（Mooshroom）`mooshroom`
- 样子：红色/棕色蘑菇背毛的牛，生成于蘑菇岛。
- 生命 10；用碗右键获得蘑菇煲；用剪刀剪毛掉落蘑菇并变普通牛；可繁殖（小麦）。
- 掉落：生牛肉、皮革（剪毛后）、蘑菇。

### 猪（Pig）`pig`
- 样子：粉红色猪，成年高约 0.9 格。
- 生命 10；生成于草原/森林等。
- 行为：被胡萝卜/马铃薯/甜菜吸引；可繁殖；被闪电击中变僵尸猪灵。
- 掉落：生猪排 1–3；被火烧死掉熟猪排。

### 鸡（Chicken）`chicken`
- 样子：白色鸡，高约 0.7 格。
- 生命 4；生成于草地；**下蛋**（每 5–10 分钟随机掉落鸡蛋）。
- 行为：被小麦种子/西瓜种子/南瓜种子吸引；可繁殖；可被摔死（重力）。
- 掉落：生鸡肉 1、羽毛 0–2；被火烧死掉熟鸡肉。

### 绵羊（Sheep）`sheep`
- 样子：白色（或 1/16 概率其他色）毛茸茸的羊。
- 生命 8；生成于草地。
- 行为：吃草（啃食草方块并恢复羊毛）；可染色；可繁殖（小麦）；剪毛掉落 1–3 羊毛。
- 掉落：羊毛（剪/杀）、生羊肉 1–2；被火烧死掉熟羊肉。

### 兔子（Rabbit）`rabbit`
- 样子：多种毛色的短耳兔。
- 生命 3；生成于沙漠/花森林/雪原等（颜色随生物群系）。
- 行为：跳跃移动；被胡萝卜/蒲公英吸引；可繁殖；吃胡萝卜作物。
- 掉落：生兔肉、兔皮 0–1、兔脚 1/10 概率（时运影响）；被火烧死掉熟兔肉。

### 山羊（Goat）`goat`
- 样子：灰白带角的羊，喜欢站在高处。
- 生命 10；生成于山地生物群系。
- 行为：会跳跃冲撞（撞飞实体，不主动攻击）；**随机冲撞玩家**（小概率）；用桶接山羊奶；繁殖（小麦）。
- 掉落：生羊肉、山羊角 1–2（冲撞撞到方块时掉落）。

### 熊猫（Panda）`panda`
- 样子：黑白熊猫，生成于竹林。
- 生命 20；被动（但护食）。
- 行为：吃竹子；有 7 种性格（正常、懒惰、忧愁、顽皮、攻击性、体弱、棕色）；攻击性熊猫会咬玩家；繁殖（竹子，需附近有竹）。
- 掉落：竹子（吃时掉落）。

### 蜜蜂（Bee）`bee`
- 样子：黄黑条纹蜜蜂。
- 生命 10；生成于蜂巢附近（花森林/平原等）。
- 行为：采集花粉（使作物生长加速）、回巢酿蜜；被攻击时**群体蜇人**（中毒，蜇后死亡）；繁殖（花）。
- 掉落：无（死亡无掉落）。

### 狐狸（Fox）`fox`
- 样子：红狐/雪狐（雪原变体）。
- 生命 10；被动（除非玩家主动攻击）。
- 行为：夜间活动；叼物品；攻击鸡/兔子；可繁殖（甜浆果）；信任玩家后接受驯养（喂甜浆果繁殖的幼狐信任）。
- 掉落：无。

### 蝾螈（Axolotl）`axolotl`
- 样子：粉红/棕/青/金/蓝色（蓝色极稀有）的小型蝾螈，水中生物。
- 生命 14；生成于繁茂洞穴的水中。
- 行为：被动；装死（受伤概率假死）；攻击鱼、鱿鱼；**帮助玩家战斗**（玩家击杀鱼后短暂加成）；可繁殖（热带鱼桶）。
- 掉落：无。

## 驯养与坐骑类

### 马（Horse）`horse`、驴（Donkey）`donkey`、骡（Mule）`mule`
- 样子：多种毛色（白/黑/棕/栗/斑）的马；驴为灰棕色长耳；骡为马+驴杂交。
- 生命 15–30（随机）；生成于平原/草原。
- 行为：可驯服（空手骑乘，喂小麦/苹果/糖/金苹果提升驯服度）；马可装备马铠（铁/金/钻石）与马鞍；驴/骡可驮箱子（15 格）。马跳跃高度与速度随机。
- 繁殖：马+马（金苹果/金胡萝卜）；马+驴→骡。
- 掉落：皮革 0–2；被火烧死掉熟马肉。

### 骷髅马（Skeleton Horse）`skeleton_horse`
- 样子：灰白色骷髅马。
- 生命 15；生成于雷暴（骷髅陷阱马）。
- 行为：可驯服（骑乘），免疫水下溺水；不能繁殖。
- 掉落：骨头 0–2。

### 僵尸马（Zombie Horse）`zombie_horse`
- 样子：绿色腐尸马。
- 生命 15；仅命令/刷怪蛋生成。
- 掉落：腐肉 0–2。

### 骆驼（Camel）`camel`
- 样子：黄棕色双峰骆驼，1.20 新增。
- 生命 32；生成于沙漠村庄。
- 行为：可骑乘（2 人）；**可疾跑**（跳跃 2 格）；坐下；在沙上不受减速；繁殖（仙人掌）。
- 掉落：无。

### 羊驼（Llama）`llama`、行商羊驼（Trader Llama）`trader_llama`
- 样子：多色毛绒驼（白/灰/棕/奶油）。
- 生命 15–30；生成于热带草原（野羊驼）；行商羊驼由流浪商人带领。
- 行为：中立（受击吐口水）；可驯服（空手骑乘，喂干草块）；可驮地毯与箱子（15 格）；跟随羊驼队伍。
- 掉落：皮革 0–2。

### 猫（Cat）`cat`、豹猫（Ocelot）`ocelot`
- 样子：猫有 11 种毛色花纹（虎斑、黑白、橘、白、黑、暹罗等）；豹猫为金黄斑点野猫。
- 生命：猫 10、豹猫 10；豹猫生成于丛林；猫生成于村庄。
- 行为：猫可驯服（喂生鱼），驯服后跟随、驱赶苦力怕（苦力怕惧怕猫）；豹猫被动（可用生鱼驯服为猫，1.20.4 中豹猫驯服后变猫）。
- 掉落：无。

### 狼（Wolf）`wolf`
- 样子：灰白色狼（驯服后带红项圈，可染色项圈）。
- 生命：野生 8、驯服 20；生成于森林/针叶林/古针叶林。
- 行为：中立（野生群居，受击群体反击）；驯服（喂骨头）；驯服狼攻击玩家攻击的目标；可繁殖（任意肉，需满血）；攻击骷髅/绵羊/兔子等。
- 掉落：无。

### 鹦鹉（Parrot）`parrot`
- 样子：红/蓝/绿/青/灰 5 色鹦鹉。
- 生命 6；生成于丛林。
- 行为：可驯服（小麦种子），驯服后站在玩家肩上；模仿附近生物声音；可繁殖（曲奇会毒死）。
- 掉落：羽毛 1–2。

## 水中生物

### 鱿鱼（Squid）`squid`
- 样子：深蓝色鱿鱼，触手摆动。
- 生命 10；生成于海洋/河流。
- 行为：水中游动；被攻击喷墨（墨囊粒子）；上岸会窒息。
- 掉落：墨囊 1–3。

### 发光鱿鱼（Glow Squid）`glow_squid`
- 样子：青蓝色发光鱿鱼（发光度 10）。
- 生命 10；生成于深暗水域（地下湖泊）。
- 掉落：荧光墨囊 1–3。

### 鳕鱼（Cod）`cod`、鲑鱼（Salmon）`salmon`、河豚（Pufferfish）`pufferfish`、热带鱼（Tropical Fish）`tropical_fish`
- 样子：鳕鱼银白细长；鲑鱼粉红带斑；河豚圆胖带刺；热带鱼色彩艳丽（3000+ 组合）。
- 生命均 3；生成于海洋/河流（对应生物群系）。
- 行为：水中游动；河豚受击膨胀并给附近实体中毒。
- 掉落：生鱼/生鲑鱼/河豚/热带鱼（各对应）；用桶可捕捉（鱼桶）。

### 海龟（Turtle）`turtle`
- 样子：绿色海龟。
- 生命 30；生成于沙滩。
- 行为：在出生海滩下蛋（海龟蛋，可孵化）；幼龟回海；繁殖（海草）；被海草吸引。
- 掉落：海草（捕食时）；被玩家击杀掉落 0–1 海龟壳（概率较低）；海龟蛋用于孵化，孵出幼龟。

### 海豚（Dolphin）`dolphin`
- 样子：灰蓝海豚。
- 生命 10；生成于海洋（非冻洋）。
- 行为：中立（受击反击）；喜欢追逐船；喂生鳕鱼/生鲑鱼获得"海豚恩惠"（游泳加速）；会引领玩家到宝藏（喂食后）。
- 掉落：生鳕鱼 0–1。

### 青蛙（Frog）`frog`、蝌蚪（Tadpole）`tadpole`
- 样子：绿色/橙色/白色青蛙（随生物群系变种）；蝌蚪为小黑蝌蚪。
- 生命：青蛙 10、蝌蚪 5；青蛙生成于沼泽；蝌蚪由青蛙卵孵化（1.20.4 青蛙卵在青蛙繁殖时产下）。
- 行为：青蛙跳高、吃小型生物（吃小型岩浆怪掉落荧光墨囊）；可繁殖（黏液球）；蝌蚪长大后变成所在生物群系对应颜色青蛙。
- 掉落：无（青蛙）；蝌蚪无。

### 嗅探兽（Sniffer）`sniffer`
- 样子：深棕色带壳的史前兽，1.20 新增，体型较大（约 1.9 格高）。
- 生命 14；不自然生成，由嗅探兽蛋孵化（蛋在沉船/海底遗迹考古获得）。
- 行为：低头嗅探地面，挖出火把花种子与瓶子草荚果；不会攻击；可繁殖（火把花种子）；在沙滩产卵。
- 掉落：无（击杀无掉落）。

## 其他

### 蝙蝠（Bat）`bat`
- 样子：小型棕色蝙蝠（1.20.3 更新了新模型/纹理）。
- 生命 6；生成于黑暗洞穴。
- 行为：无攻击性；随机飞行；可被杀死。
- 掉落：无。

### 悦灵（Allay）`allay`
- 样子：蓝色小精灵，扇动翅膀。
- 生命 20；生成于掠夺者前哨站/林地府邸的笼子中。
- 行为：被动；拾取并递给玩家指定物品（给予物品后）；跟随玩家；可复制（用唱片机+任意唱片）；被玩家喂食后信任。
- 掉落：无。

### 流浪商人（Wandering Trader）`wandering_trader`
- 样子：蓝色长袍+白色头巾的商人。
- 生命 20；随机出现在村庄/玩家附近（每 20–30 分钟出现，2–3 天后消失）。
- 行为：售卖随机物品（用绿宝石）；喝隐身药水；带 2 只行商羊驼。
- 掉落：无（只掉经验）。
