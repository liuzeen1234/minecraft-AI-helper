# 实体总览与通用机制

> 目标版本：Java 版 1.20.4。实体分为生物（Mob，有生命值、可移动）与非生物实体（投射物、物品、交通工具等）。

## 实体分类

| 分类 | 说明 | 示例 |
|---|---|---|
| 被动生物 | 不会主动攻击玩家 | 牛、猪、鸡、羊、村民、鱼、悦灵 |
| 中立生物 | 被激怒后才攻击 | 末影人、猪灵、狼、铁傀儡、熊 |
| 敌对生物 | 主动攻击玩家 | 僵尸、骷髅、苦力怕、蜘蛛 |
| 效用生物 | 玩家创造的守护/辅助单位 | 铁傀儡、雪傀儡、悦灵（亦属被动） |
| 首领 | 大型 Boss 战单位 | 末影龙、凋灵、监守者 |
| 非生物实体 | 无生命的可交互对象 | 物品、箭、船、矿车、盔甲架、画 |

## 通用机制

### 生命值（Health）
- 每个生物有最大生命值（`MaxHealth` NBT）。伤害单位为"半颗心"（1 点 = 半颗心）。
- 通用护甲/护甲韧性、抗性提升、火焰保护等减免伤害；保护附魔减免魔法/爆炸/火焰等。

### 生成（Spawning）
- **自然生成条件**：敌对生物需要**方块光照 0**（1.18+ 改为方块光照+天空光照的算法，1.19.3 起天空光照不直接计入，但仍需亮度 0 判定）且可刷怪方块上；距离玩家 24–128 格之间；不在玩家视线内等。
- 被动生物需要足够亮度（≥9）与空间。
- 生成受**怪物上限**（每玩家每区域 70 只敌对生物）与**刷怪蛋/刷怪笼/结构生成**（村庄、遗迹、堡垒等）影响。
- 生物群系决定可生成的生物（如沙漠有尸壳、丛林有豹猫）。

### 消失（Despawn）
- **立即消失**：距玩家超过 128 格（球形半径）的多数生物立即消失。
- **随机消失**：距玩家 32–128 格之间，每游戏刻有 1/800 概率随机消失（按类型与是否手持物品/NBT 判定）。
- **持久化**：手持物品、有名字（name tag）、被玩家喂食（驯服）、处于村庄等生物不会随机消失；可被 `/summon ... {PersistenceRequired:1}` 强制持久。
- 大多数生物 30 秒不移动且无目标会停止 AI 活动（"惰性"）。

### 掉落物（Drops）
- 击杀时掉落物品：常见于对应条目；抢夺附魔增加部分掉落数量与概率（掉落物与概率见各生物条目）。
- 被玩家或驯服狼击杀才计入玩家击杀（掉落经验与"玩家击杀"条件掉落）。
- 经验值：被动生物 1–3，中立 5，敌对 5–20（不同生物不同），Boss：末影龙首次击杀 12000、之后 500，凋灵 50，监守者 5。


### AI 与寻路（Pathfinding）
- 生物有目标系统（无目标→游荡→目标行为链）；寻路基于方块（不穿墙）；跳跃寻路、攀爬（梯子）、游泳。
- 视野：多数敌对生物探测半径 16 格（苦力怕 16、僵尸 16、骷髅 16 等），末影人 64 格；垂直 ±4 格。
- 大多数生物受"刻"驱动更新 AI（每秒 20 次），受 TPS 影响。
- 生物 AI 关闭（失活）条件：距玩家 32 格以上且无目标时随机跳过 AI 更新。

### 实体共通 NBT（Java 版 1.20.4 要点）
- 通用：`id`、`Pos`、`Motion`、`Rotation`、`UUID`、`CustomName`（JSON 文本）、`CustomNameVisible`、`Silent`、`NoGravity`、`Glowing`、`Invulnerable`、`Tags`（自定义标签）、`Passengers`、`Persistent`/`PersistenceRequired`、`DeathTime`、`Health`、`HandItems`/`ArmorItems`、`CanPickUpLoot`、`NoAI`、`LeftHanded` 等。
- 生物专属标签见各条目（如苦力怕 `powered`、僵尸 `IsBaby`、村民 `Profession`、驯服 `Owner` 等）。
- 用 `/summon <id> <pos> {NBT}` 与 `/data` 读写；`/summon` 支持刷怪事件（spawn event）如 `minecraft:become_charged`（基岩版风格；Java 版用 NBT）。

### 实体尺寸（Java 版）
- 不同生物碰撞箱大小不一；标准：玩家 0.6×1.8、僵尸 0.6×1.95、骷髅 0.6×1.99、牛 0.9×1.4、鸡 0.4×0.7、蜘蛛 1.4×0.9 等；幼年体约为成年一半。

## 特殊机制实体

- **刷怪蛋（Spawn Egg）**：创造模式可生成对应生物；刷怪蛋会忽略光照/数量上限（需空间）。
- **玩家（Player）**：生命 20、攻击伤害 1（空手）；`/summon` 不能生成玩家。
- **经验球（Experience Orb）**：拾取后增加经验；掉落来源见各生物。
- **掉落物（Item）**：实体化的物品；60 秒（5 分钟）后消失；可被漏斗吸收；受爆炸/水流影响。
