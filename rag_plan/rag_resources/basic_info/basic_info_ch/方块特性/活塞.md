# 活塞

**活塞（Piston）** 是一种被红石信号激活时可以推动大多数方块和实体的方块。

**黏性活塞（Sticky Piston）** 和普通活塞的功能相同，但当红石信号结束时也能拉回被移动的方块；普通活塞只会将方块留在原处。

## 基础属性

| 属性 | 值 |
|---|---|
| 硬度 | 1.5 |
| 爆炸抗性 | 0.5 |
| 合适挖掘工具 | 镐 |
| 红石导体 | 否 |
| 窒息生物 | 未伸出时：是；伸出时：否 |
| 最大堆叠 | 64 |
| 可再生 | 是 |

## 生成与获取

- 普通活塞不会在世界中自然生成。
- 自然生成：丛林神庙内生成 3 个黏性活塞；远古城市中心红石地下室生成 5 个黏性活塞。
- 合成：3 木板 + 4 圆石 + 1 铁锭 + 1 红石粉 → 1 活塞。
- 黏性活塞：1 活塞 + 1 黏液球 → 1 黏性活塞。
- 破坏：合适工具为镐；移动中的活塞不能被挖掘破坏。活塞/黏性活塞被破坏后掉落自身并破坏其伸出的活塞头；活塞头被破坏后会破坏生成它的活塞；移动中的活塞被破坏后掉落对应方块。

## 放置与激活

- 活塞放置时永远朝向玩家。附着性方块（如拉杆）可放在活塞或黏性活塞上，但不能放在激活状态的活塞侧面。
- 激活后，活塞头在启动延迟后伸出并移动前方方块；取消激活后活塞头收回（黏性活塞会尝试拉回前方方块）。
- 黏性活塞只有在缩回时才有黏性，静止时活塞头上的方块不会被黏住。

激活方式：

- 激活的红石线指向活塞（除非活塞面向红石线）。
- 毗邻的充能方块（强充能或弱充能），除非活塞面向该方块。
- 毗邻的红石火把，除非活塞面向火把或火把插在活塞上。
- 指向活塞且输出信号的中继器、比较器、侦测器，除非活塞面向该元件。
- 其他毗邻且开启的电源，除非活塞面向该元件。
- **半连接性**（仅 Java 版）：活塞能被任何可以激活其上方一格空间的东西激活，无论那一格是什么方块，也无论活塞朝向。
- 活塞本身不是红石导体，不能被充能传导。

## 启动延迟

从激活到活塞真正开始伸出/收回的时延：

- 基岩版：固定 2 游戏刻（0.1 秒）。
- Java 版：
  - 若活塞在执行计划刻或方块事件时被激活 → 延迟 0 游戏刻（同刻启动）。
  - 若活塞因实体、方块实体更新或玩家操作而被激活 → 延迟 1 游戏刻（下一刻启动）。

## 移动方块结构规则

方块会尝试被**推动**的情况：

- 方块位于将要伸出的活塞前方。
- 方块位于另一个被推动方块的移动方向前方。

方块会尝试被**拉动**的情况（仅黏性活塞/黏液块/蜂蜜块）：

- 方块位于将要收回的黏性活塞活塞头前方。
- 方块位于将要移动的黏液块/蜂蜜块移动方向的侧方或后方。

若同时符合推动和拉动条件，视为推动。

方块的推拉行为分类：

- 可以被推动，也可以被拉动。
- 可以被推动，但不可以被拉动。
- 被推动时会被破坏，且不可以被拉动。
- 不可以被推动，也不可以被拉动。

### Java 版常见方块推拉行为

| 方块类别 | 行为 |
|---|---|
| 屏障、信标、基岩、命令方块、附魔台、末地传送门/折跃门、末影箱、砂轮、拼图方块、唱片机、光源方块、磁石、刷怪笼、移动的活塞、下界传送门、黑曜石、已伸长的活塞、活塞头、强化深板岩、重生锚、幽匿系列方块、结构方块 | 不能被推动或拉动 |
| 木桶、蜂箱、蜂巢、高炉、酿造台、箱子、雕纹书架、阳光探测器、发射器、投掷器、熔炉、漏斗、讲台、烟熏炉、陷阱箱 | 不能被推动或拉动（Java 版）；基岩版可推拉 |
| 带釉陶瓦 | 能被推动，不能被拉动 |
| 地毯 | 可推可拉；向下拉动时被破坏并掉落为物品 |
| 钟、蜡烛、灯笼、灵魂灯笼 | 推动时会被破坏（可掉落物品），不能被拉动 |
| 紫水晶簇、竹子、床、按钮、仙人掌、蛋糕、雕刻南瓜、可可果、门、火、花盆、生物头颅、物品展示框、南瓜灯、梯子、熔岩、树叶、拉杆、睡莲、西瓜、苔藓块、蘑菇、下界疣、画、滴水石锥、压力板、红石比较器/粉/中继器/火把、树苗、脚手架、海泡菜、潜影盒、雪、甘蔗、火把、绊线、绊线钩、海龟蛋、藤蔓、水等大量“附着性/非固体”方块 | 推动时会被破坏并可掉落物品，不能被拉动 |
| 铁砧 | 不能被拉动；仅在下落状态时可被推动 |
| 混凝土粉末、沙砾、红沙、沙子 | 可正常推拉，但下方无支撑时会掉落而非黏在黏性活塞上 |
| 铁轨 | 可正常推拉，但下方无支撑时会被破坏并掉落为物品 |

### 无法移动的情况

以下情况下，活塞无法推动方块（黏性活塞无法拉回方块，但仍可收回活塞头）：

- 移动方块结构总数超过 12 个。
- 黏性活塞尝试拉回不可拉动的方块。
- 移动方块结构会被移动超过建筑高度上限或下限。
- 移动方向前方有不可推动的方块阻挡。

### 时序细节

- 移动方块结构移动时，其上附着性方块会被破坏，前方的推动破坏方块也会被破坏。
- 通常 2 游戏刻（0.1 秒）后移动方块结构到位；某些情况可在更短时间内到位，称为**瞬间到位**。
- 若黏性活塞收到小于 3 游戏刻（0.15 秒）的短正脉冲信号，可能无法在信号消失时拉回已推出的方块结构。
- 活塞伸出/收回时会发出以自身为中心 31×31×31 范围内可听到的声音。

## 推动实体

- 移动方块结构会对范围内实体施加推力，使其跟随移动。
- 若实体无法移动，方块可能推入实体；若该方块是窒息方块，可能导致生物窒息死亡。
- 绝大多数实体可被推动；区域效果云、`Marker=true` 的盔甲架、展示实体（仅 Java 版）、交互实体（仅 Java 版）和标记（仅 Java 版）不会被推动。
- 被正在移动的黏液块推动的实体会以更高速度弹开。
