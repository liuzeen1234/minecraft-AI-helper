# 特殊与液体传送门方块

> 目标版本：Java 版 1.20.4。

## 不可破坏方块（生存模式无法获取/破坏）

### 基岩（Bedrock）
- 样子：深灰黑色带颗粒纹理的方块。
- 特性：硬度 -1（不可破坏）；世界底部（Y=-64）与顶部（Y=320 顶层）的边界；创造模式可放置；不可被活塞推动、不可被爆炸破坏。

### 屏障（Barrier）
- 样子：**隐形**方块，仅在持有屏障物品时显示为红色斜线圆标。
- 特性：硬度 -1；只存在于创造模式；阻挡实体、光照与红石信号；用于地图制作边界。

### 光源方块（Light Block）
- 样子：隐形方块，持有物品时显示为黄色发光圆点（0–15 级）。
- 特性：硬度 -1；创造模式放置；只提供指定等级光照，不阻挡任何东西；用于地图光照控制。

### 命令方块（Command Block）
- 样子：灰绿色方块体带斜面屏幕与发光边缘（脉冲/连锁/循环三种）；有 3 种类型。
- 特性：硬度 -1；仅创造/管理员可用；执行命令；可被红石激活（脉冲型）、连锁型（上一个命令方块激活后执行，需要朝向）、循环型（每刻执行）；`/give` 获取或放置后设置。可被 `-{mode}` 设定为脉冲/连锁/循环。

### 结构方块（Structure Block）
- 样子：灰白/蓝色带网格的方块体（数据/保存/加载/角点四种模式）。
- 特性：硬度 -1；保存与加载结构（.nbt）；用于地图制作与结构复制；默认需管理员。

### 拼图方块（Jigsaw Block）
- 样子：绿色方块带拼图凹槽纹理。
- 特性：硬度 -1；生成结构时连接结构片段（target/pool 逻辑）；用于自定义结构生成（如古城、遗迹）。

### 强化深板岩（Reinforced Deepslate）
- 样子：深灰色带铆钉纹理的深板岩。
- 特性：硬度 55（挖掘需约 1200 秒，生存极难破坏）；生成于远古城市；用于结构保护，不可被活塞推动。

## 传送门与维度方块

### 下界传送门（Nether Portal）
- 样子：紫色发光传送门方块（发光度 11），带有流动的紫色粒子。
- 特性：由黑曜石框架（至少 4×5）用打火石/火焰弹点燃；进入后传送到下界（坐标换算：主世界÷8）；传送门方块不可被普通手段破坏（可用水/熔岩熄灭框架，方块会消失）；会发出紫色粒子。

### 末地传送门（End Portal）
- 样子：黑色传送门方块带星点光效。
- 特性：在要塞末地传送门框架（12 块框架+末影之眼激活）中生成；进入后传送到末地；不可破坏；框架方块（End Portal Frame）带绿色雕纹，有眼睛插槽。

### 末地折跃门（End Gateway）
- 样子：黑色细框传送门，中心有紫色光柱。
- 特性：末地外岛与主岛间的快速传送；不可破坏；只在末地龙死后激活。

### 末地水晶（End Crystal，实体）
- 样子：玻璃球体+底座，顶端发光。
- 特性：见实体篇；为末影龙回血；可被玩家放置/摧毁。

## 液体方块

### 水（Water）
- 样子：半透明蓝色液体，流动时有波纹动画。
- 特性：硬度 100（特殊），无工具（不可挖掘）；可流动（最远 7 格水平、向下无限）；源方块可用桶收集；方块可含水（见总览）；实体在水中减速、可游泳；熔岩浇上形成黑曜石/石头；流速影响运输。

### 熔岩（Lava）
- 样子：橙红色发光液体（发光度 15），表面带波纹。
- 特性：不可用桶无限收集（源可）；流动比水慢（最远 4 格）；接触造成火焰伤害并点燃可燃物；水浇熔岩：源→黑曜石，流→石头；熔岩+灵魂沙→气泡柱；熔岩炼药锅可销毁物品。

### 气泡柱（Bubble Column）
- 样子：水中向上/向下的气泡流。
- 特性：由灵魂沙（上升柱）或岩浆块（下降柱）产生；可推动实体上升/下降；可被船破坏；用于水电梯。

## 特殊机制方块

### 黏液块（Slime Block）
- 样子：半透明绿色果冻状方块。
- 特性：硬度 0，任意工具；**弹跳**：实体落上反弹（保留部分动量，受跳跃加成）；**可被活塞推动**并带动相邻方块（传递移动，产生"弹射"装置）；可作为红石机械的"移动载体"；不导电。

### 蜂蜜块（Honey Block）
- 样子：半透明金色果冻状方块，表面带蜂窝纹理。
- 特性：硬度 0，任意工具；实体在其上减速（走不动）、**摔落不受伤**（掉落免疫）；可被活塞推动/拉动（**拉**动相邻方块，与黏液块不同）；粘住实体；用于红石机械（拉动式传递）。

### 冰类（Ice / Packed Ice / Blue Ice）
- 样子：见自然篇；冰面光滑，实体在其上打滑；浮冰与蓝冰可被活塞推动（冰类可被活塞推动），蓝冰用于"蓝冰船道"高速运输。

### 浮冰/冰与红石
- 浮冰与蓝冰**不是红石导体**（信号不能穿过）。

### TNT（TNT）
- 样子：红色块体带白色绑带纹理。
- 特性：硬度 0，任意工具；被红石信号/火焰/爆炸/打火石激活后 4 秒（80 游戏刻）爆炸；爆炸威力 4；可被活塞推出（下落中仍会爆炸）；TNT 矿车变体见实体篇。
