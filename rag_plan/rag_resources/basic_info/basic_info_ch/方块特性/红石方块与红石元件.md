# 红石方块与红石元件（红石块 / 压力板 / 红石中继器 / 侦测器 / 红石比较器）

> 来源：中文 Minecraft Wiki（Fandom 镜像，minecraft.fandom.com/zh/wiki/红石中继器 重定向页内容，实际覆盖红石方块与相关红石元件）
> 目标版本：Java 版 1.20.1 / 1.20.4

## 红石块（Block of Redstone）

红石块（Block of Redstone）是用9个红石粉合成的方块，相当于一个可被活塞推动的不能关闭的红石电源。

- 命名空间ID：`redstone_block`；最大堆叠64；可再生；合适挖掘工具为镐（任意品质），破坏后掉落自身。
- 红石块会自然生成于远古城市中心的地下室中。

红石块总是保持开启，它不能被关闭，红石块会：

- 激活任何毗邻的红石线，包括它上面的和下面的红石线，向其提供15级的信号等级。
- 激活任何四周的背对红石块的红石中继器和红石比较器，向它们提供15级的信号等级。
- 激活附着其上的红石火把使其熄灭。
- 激活任何毗邻的机械元件（如门、红石灯等），包括红石块上面的和下面的红石元件。但活塞不能被任何在它前面的电源常规激活。
- 与红石块相邻的红石导体不会被充能。
- 向红石比较器的边侧输入信号（仅Java版）。

红石块表现的性质和强充能方块类似，但其实它不是红石导体，例如放在箱子上方时不会阻止箱子被开启。如果把一个红石火把放在红石块上面，它将在1红石刻后熄灭并不会重新点亮。红石块可以被活塞移动，而且水与熔岩会绕过红石块而不影响它。

## 压力板（Pressure Plate）

压力板是一种可以用来探测玩家、生物等实体的方块。它有四种变种：

- **木质**：可以探测所有实体，发出15信号强度，有11种变种。
- **石头、磨制黑石**：只能探测玩家和生物，发出15信号强度。
- **轻质测重**（金）：可以探测所有实体，信号强度随着实体的增加而增加（每个实体+1，最高15）。
- **重质测重**（铁）：与轻质相似，但增加信号强度需要的实体更多（每10个实体+1，最高15）。

压力板可用于合成探测铁轨或者烧炼物品，也可以作为红石元件使用。在以下情况，压力板将被摧毁并且作为物品掉落：附着的方块移动、消失或被摧毁；活塞尝试推动之或者将一个方块移动到其位置。水和熔岩会绕过压力板而不影响它。

**开启条件**：上面（具体来说，是在压力板所在方块的(0.125,0,0.125)到(0.875,0.25,0.875)这个长方体之内）有实体时（即使实体的碰撞箱只有一小部分在其中），压力板会被开启。石质压力板只会被生物开启（包括玩家），而木质压力板可以被除了投掷物及下落的方块以外的所有的实体（包括玩家、生物、物体、箭、经验球、浮漂等）开启。

## 红石中继器（Redstone Repeater）

红石中继器在红石电路中是用于"中继"红石信号并放大、阻止信号倒流、或者"锁存"信号状态的方块。

- 中继器只能放置在上表面边缘完整的方块上，包括漏斗、堆肥桶、上半台阶等。在基岩版中，还可以放置在石墙和栅栏上。
- 中继器有前侧与后侧之分——纹理上的箭头指向的方向就是前侧。中继器上还有两个小红石火把——火把的颜色指示输出是否为开（输出关时为暗红色，开时为亮红色），两根火把之间的距离表示中继器在信号传输中产生的延迟（1~4红石刻，即2~8游戏刻）。
- 中继器无法被上下左右和逆向的红石信号所激活。中继器高度为0.125（1/8）格。
- 红石中继器在下列情况下会被破坏并掉落：附着方块移动、消失或被破坏；在Java版中，有水流过；活塞试图推动它，或者将方块推入其所在的位置。若熔岩流过红石中继器，中继器会被破坏，但不会掉落。

**承载信号**：中继器只能从后侧往前侧传输信号，但是中继器的这个特性可以通过边侧的输入变更（见信号锁存）。

红石中继器可以通过下列元件在后侧输入激活：开启的电源元件（例外：侦测器只激活指向的中继器）；激活的红石粉；输出信号且指向该中继器的红石比较器或另一个中继器；充能方块（也包括任何被充能的机械元件，如发射器、红石灯）。

红石中继器可以通过前侧激活或充能下列元件：激活红石粉；激活红石比较器或后侧朝向中继器的另一个中继器；强充能任何红石导体（含机械元件）；激活毗邻且面向中继器的活塞以外的任何红石机械元件；锁存边侧朝向它的另一个中继器。

通常称被红石中继器充能的红石导体为"**强充能**"，而红石粉充能的则称为"**弱充能**"。强充能的红石导体可以激活毗邻的红石粉以及其他的红石元件。

## 侦测器（Observer）

侦测器是当一个面对的方块传来方块更新时会发出红石信号的方块。

- 在Java版中，侦测器用于侦测目标方块的方块状态的变化，或者方块的放置或移除（方块状态的改变，而不是方块实体数据的改变）。这意味着农作物的生长可以被侦测到，因为它们是方块状态的一部分。侦测器充当一个方块更新检测器的角色，它会响应面前造成PP更新的事件。
- 在基岩版中，侦测器充当方块更新感应器（BUD）使用，且能侦测版本中一切的方块变化。基岩版中造成一次更新的事件和它们传播的方式与Java版十分不同，导致两个版本分别有另一个版本不能侦测到的变化。
- 当侦测到某事物时，侦测器会向输出面发出信号强度为15，持续2游戏刻（1红石刻）的脉冲。脉冲能激活红石粉、红石中继器或在侦测器输出端一侧的机械元件等，也会强充能输出端朝向的红石导体至15等级。
- 在Java版中，侦测器有1红石刻的延迟。在基岩版中，侦测器本来应当也有1红石刻的延迟，但因为漏洞MCPE-15793而实际上有2红石刻延迟。
- 当侦测器本身被活塞移动到位后，这既算方块状态的变化也算作一次方块更新。侦测器（在Java版中，正在输出信号的除外）在被推或拉到位后再过2游戏刻（仅Java版）或4游戏刻（仅基岩版）会发出脉冲。
- 尽管侦测器阻挡光，但它不是红石导体：它不能被外部红石信号充能，也不能被自己的输出信号充能。
- 因为侦测器在Java版中可以侦测方块状态的改变，而不是方块更新（狭义），它们可以比BUD侦测范围更广的现象（因为一些方块状态的改变不会引起方块更新）。在基岩版中，侦测器会侦测方块更新而不是方块状态的改变，因此它们与其他BUD类型有着相同的功能。

## 红石比较器（Redstone Comparator）

红石比较器是能使红石信号保持、比较、作差或检测特定数据值（主要是容器装载量）的红石元件方块。

- 红石比较器可以放置在任何上表面边缘完整的方块（包括倒台阶、楼梯和漏斗）上。在基岩版，还可以放置在石墙和栅栏上。
- 红石比较器有前后之分——上部的三角指向的是前方。放下比较器时，比较器的后方（即输入侧）朝向玩家。比较器上后侧有两根小红石火把，靠前端则有一根。当输入比较器的信号大于零时，后侧的火把会变亮，三角也会变红。前端火把的状态可以由使用物品键切换：关闭、熄灭（指示比较器处于"比较模式"），打开、亮起（指示比较器处于"作差模式"）。
- 红石比较器可以从后侧及边侧（左右侧）接受信号。边侧输入只能从红石块（仅Java版）、红石粉、红石中继器、侦测器（仅Java版）、避雷针（仅Java版）和其他比较器接收。红石比较器的前侧是输出端。
- 信号经过红石比较器需要1红石刻（2游戏刻或不考虑游戏卡顿为0.1秒），不论输入端是前侧还是边侧。仅1刻的输入信号变化红石比较器通常不会有反应——例如单刻脉冲的发生器在边侧输入时会被认为总是无信号，在后侧输入则认为是保持开启。
- 红石比较器有四大用途：保持信号强度、比较信号强度、信号强度作差以及检测方块的状态（主要为容器的装载量）。
