# 命令集总览与语法规则

> 目标版本：Java 版 1.20.4。详细语法与示例见同目录 `命令集-玩家与实体命令.md`、`命令集-数据与执行命令.md`、`命令集-世界与服务器命令.md`。

## 通用规则

- 在聊天栏输入 `/` 开头命令；单机需开启"允许作弊"；服务器需对应权限等级。
- 命令不区分大小写（命令名与参数名均可小写），但资源 ID、NBT、JSON 文本区分大小写。
- 多数命令仅服务端执行；客户端命令（如 `/help`）直接返回。
- 命令方块（脉冲/连锁/循环）与函数（数据包）可自动执行命令；`@s` 在命令方块中代表"最近执行的实体/方块所有者"（1.13+ 为命令方块本身所在位置的"执行者"）。

## 权限等级（Java 版）

| 等级 | 说明 |
|---|---|
| 0 | 所有玩家（聊天命令 /help、/msg、/me 等；/seed 在服务器需等级 2） |
| 1 | 不常用（原为 /give 等? 现代版本多数命令 2） |
| 2 | 作弊命令（/gamemode、/tp、/give、/summon、/setblock 等） |
| 3 | 服务器管理（/ban、/kick、/op、/whitelist、/tick 等） |
| 4 | 服务器所有者（/stop、/save-off? /stop 等级 4、/debug 等） |

- 常用权限：命令方块需要 2；`/tick`、`/ban`、`/kick`、`/op`、`/whitelist` 等需要 3；`/stop`、`/save-all`、`/debug` 等需要 4。具体命令的权限要求见各分篇（服务端以实际权限配置为准）。

## 目标选择器

| 选择器 | 含义 |
|---|---|
| `@p` | 最近玩家 |
| `@a` | 所有玩家 |
| `@r` | 随机玩家 |
| `@e` | 所有实体 |
| `@s` | 执行者自身 |
| `@n` | 最近生物? —— 仅基岩版，Java 无。不要列入！ |

Java 版只有 @p/@a/@r/@e/@s。选择器参数（方括号）：
- `[type=zombie]`、`[type=!zombie]`（排除）、`[type=#minecraft:skeletons]`（实体标签）
- `[distance=..5]`、`[x=..,y=..,z=..]`（坐标与范围）、`[dx=..,dy=..,dz=..]`（长方体）
- `[limit=3]`、`[sort=nearest|furthest|random|arbitrary]`
- `[name="名字"]`、`[nbt={...}]`、`[scores={obj=..5}]`、`[tag=标签]`、`[team=队伍]`
- `[gamemode=creative]`、`[predicate=命名空间谓词]`、`[advancements={...}]`
- 范围写法：`..5`（≤5）、`5..`（≥5）、`1..5`（1–5）。

## 坐标语法

- 绝对坐标：`100 64 -200`。
- 相对坐标：`~ ~ ~`（相对执行位置，`~5` 表示 +5）。
- 局部坐标：`^ ^ ^`（相对执行者的朝向：前/上/右，用于 `execute` 的 `facing`/`rotated` 场景）。
- 多数命令（/setblock、/fill、/summon、/tp 等）接受坐标；`~` 可省略为 `~ ~`（如 `/tp @s ~ ~5 ~`）。

## 数据格式

### NBT（Named Binary Tag）
- 用 SNBT（字符串 NBT）表示：`{key:value, list:[...]}`；如 `{powered:1b, Health:20f, Inventory:[...]}`。
- 类型后缀：`b`（字节）、`s`（短整）、`l`（长整）、`f`（浮点）、`d`（双精度）、`i`（整，可省略）；字符串 `"text"`；列表 `[]`；复合 `{}`。
- 用于 `/summon`、`/data`、`/give`（物品 NBT）、`/item` 等。

### JSON 文本组件（Text Component）
- 聊天/标题/告示牌文本的 JSON 格式：`{"text":"...", "color":"red", "bold":true}`；可嵌套 `"extra":[...]`。
- 标准格式：`{"text":"你好","color":"gold"}`；使用转义符 `\"`。
- 支持：color（颜色名或 #RRGGBB）、bold、italic、underlined、strikethrough、obfuscated、clickEvent、hoverEvent、insertion、translate（翻译键）、score（分数）、selector、keybind、nbt。
- 目标选择器在文本组件中显示实体名：`{"selector":"@p"}`。

### 资源位置（Resource Location）
- 格式 `命名空间:路径`（如 `minecraft:zombie`、`minecraft:sharpness`）；省略命名空间默认 `minecraft`。
- 用于实体 ID、方块 ID、物品 ID、进度、函数、实体标签等。
