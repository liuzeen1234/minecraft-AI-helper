# 敌对生物

> 目标版本：Java 版 1.20.4。敌对生物主动攻击玩家；苦力怕详见单独文件 `苦力怕.md`。

## 亡灵类（主世界）

### 僵尸（Zombie）`zombie`
- 样子：绿色腐尸人形，双臂前伸。
- 生命 20；生成于主世界夜间亮度≤0 处。
- 行为：追击玩家与村民；白天燃烧（未戴头盔时）；可感染村民/转换为尸壳或溺尸；僵尸围城（夜晚村庄）。
- 掉落：腐肉 0–2、铁锭/胡萝卜/马铃薯/铁剑（罕见）；装备附魔（罕见）。

### 尸壳（Husk）`husk`
- 样子：黄褐色干燥腐尸。
- 生命 20；生成于沙漠。
- 行为：同僵尸，但**白天不燃烧**；攻击附加"饥饿"效果。
- 掉落：腐肉、罕见物品。

### 溺尸（Drowned）`drowned`
- 样子：青绿色水下腐尸。
- 生命 20；生成于海洋/河流水下。
- 行为：水下追击玩家；白天不燃烧；**掷三叉戟**（远程，普通+难度）；手持三叉戟/钓鱼竿。
- 掉落：腐肉、铜锭（罕见）、三叉戟（罕见，手持时）、钓鱼竿。

### 骷髅（Skeleton）`skeleton`
- 样子：白色骷髅弓手。
- 生命 20；生成于主世界夜间/下界。
- 行为：远程射箭（8–10 格射程，普通难度）；白天燃烧；走位躲避玩家。
- 掉落：骨头 0–2、箭 0–2；罕见弓/盔甲。

### 流浪者（Stray）`stray`
- 样子：灰白色带冰霜的骷髅。
- 生命 20；生成于积雪/冰原生物群系。
- 行为：射出的箭附带**缓慢**效果（30 秒）；白天不燃烧。
- 掉落：骨头、箭（缓慢之箭）。

### 凋灵骷髅（Wither Skeleton）`wither_skeleton`
- 样子：黑色骷髅，持石剑，高约 2.4 格。
- 生命 20；生成于下界要塞。
- 行为：攻击附带**凋灵**效果（10 秒）；跳斩。
- 掉落：骨头、煤炭、凋灵骷髅头颅（2.5% 概率，抢夺提升）。

## 节肢与洞穴类

### 蜘蛛（Spider，见中立篇——夜间敌对）

### 洞穴蜘蛛（Cave Spider）`cave_spider`
- 样子：蓝灰色小型毒蜘蛛。
- 生命 12；生成于废弃矿井（刷怪笼）与繁茂洞穴。
- 行为：攻击附**中毒**效果（普通难度 7 秒）；可爬墙。
- 掉落：线、蜘蛛眼。

### 蠹虫（Silverfish）`silverfish`
- 样子：银灰色小型爬虫。
- 生命 8；生成于要塞/山地石头方块中（怪物蛋）。
- 行为：钻入石质方块；被攻击时**召唤附近蠹虫**群体反击。
- 掉落：无。

### 末影螨（Endermite）`endermite`
- 样子：紫色带淡紫斑点的小型甲虫。
- 生命 8；玩家投掷末影珍珠时有概率生成。
- 行为：快速移动；被末影人攻击（末影人仇恨末影螨）。
- 掉落：无。

## 下界类

### 烈焰人（Blaze）`blaze`
- 样子：金黄色发光人形（由旋转的火焰棒组成），周围有火星粒子。
- 生命 20；生成于下界要塞。
- 行为：飞行；发射**火球**（3 连射，造成 5 伤害+点燃）；近身攻击灼烧。
- 掉落：烈焰棒 0–1（时运提升）。

### 恶魂（Ghast）`ghast`
- 样子：白色带触须的幽灵状生物（4×4 格大），流泪表情。
- 生命 10；生成于下界（除绯红森林外）。
- 行为：飞行；发射火球（可被玩家击回）；火球爆炸。
- 掉落：恶魂之泪 0–1、火药 0–2。

### 岩浆怪（Magma Cube）`magma_cube`
- 样子：橙红色带岩浆纹的弹跳方块生物（1/2/4 格大小）。
- 生命：小型 1、中型 4、大型 16。
- 行为：弹跳；大型会分裂；接触造成灼烧；掉落岩浆膏（时运）。
- 掉落：岩浆膏 0–1。

### 猪灵蛮兵（Piglin Brute）`piglin_brute`
- 样子：强壮猪人，持金斧，穿金甲。
- 生命 50；生成于堡垒遗迹。
- 行为：**无条件敌对**（不会因金甲中立）；近战攻击力高（普通难度约 13）。
- 掉落：金斧（罕见）、金粒、金质装备。

### 疣猪兽（Hoglin）`hoglin`
- 样子：红棕色獠牙巨猪。
- 生命 40；生成于绯红森林/堡垒遗迹。
- 行为：**主动攻击**玩家与猪灵（除猪灵蛮兵）；被击退可被击落；在诡异森林会转化为僵尸疣猪兽（被传送时）。
- 掉落：生猪排 2–4、皮革 0–2（被火烧死掉熟猪排）。

### 僵尸疣猪兽（Zoglin）`zoglin`
- 样子：绿色腐化疣猪兽。
- 生命 40；疣猪兽在诡异森林/主世界转化。
- 行为：无条件攻击一切生物（除苦力怕? 攻击几乎所有生物）；无法繁殖。
- 掉落：腐肉 0–1、生猪排 2–4。

## 灾厄村民（Illager）类

### 掠夺者（Pillager）`pillager`
- 样子：灰袍人形，持弩。
- 生命 24；生成于掠夺者前哨站/袭击。
- 行为：持弩远程射击；参加袭击（袭击队长戴旗帜）。
- 掉落：弩（概率）、箭 0–2、绿宝石（袭击中）。

### 卫道士（Vindicator）`vindicator`
- 样子：灰袍+深色围裙，持铁斧。
- 生命 24；生成于林地府邸/袭击。
- 行为：近战（铁斧）；名为"Johnny"的卫道士攻击一切生物。
- 掉落：铁斧（概率）、绿宝石。

### 唤魔者（Evoker）`evoker`
- 样子：深灰袍，苍白脸。
- 生命 32；生成于林地府邸/袭击。
- 行为：召唤**恼鬼**（3 只）；释放**尖牙**（地面尖刺，召唤时对玩家施放）；被玩家击杀必掉不死图腾。
- 掉落：绿宝石 0–1、不死图腾（玩家击杀必掉）。

### 恼鬼（Vex）`vex`
- 样子：灰色小精灵持铁剑。
- 生命 14；唤魔者召唤。
- 行为：穿墙飞行（无视方块）；攻击玩家。
- 掉落：无（概率铁剑）。

### 劫掠兽（Ravager）`ravager`
- 样子：灰色巨兽（高约 2.2 格）。
- 生命 100；袭击中生成。
- 行为：冲撞（击退并破坏树叶/作物）；顶飞玩家；可被击晕（短暂）。
- 掉落：鞍 1（概率）。

### 女巫（Witch）`witch`
- 样子：紫色袍+尖帽，驼背。
- 生命 26；生成于沼泽小屋/袭击/雷暴。
- 行为：投掷药水（伤害/缓慢/虚弱/中毒等）；给自己喝增益药水（治疗/抗火/迅捷）；被击中概率喝抗性药水。
- 掉落：红石粉/荧石粉/火药/蜘蛛眼/糖/玻璃瓶 0–2（各概率）。

## 海洋与洞穴类

### 守卫者（Guardian）`guardian`
- 样子：灰绿色带刺的鱼类生物（2×1 格），眼睛发光。
- 生命 30；生成于海底神殿。
- 行为：发射激光（光束伤害，需视线）；回旋镖刺攻击；用激光攻击玩家。
- 掉落：海晶碎片 0–2、海晶砂砾 0–1、生鳕鱼（玩家击杀 40%）、稀有鱼。

### 远古守卫者（Elder Guardian）`elder_guardian`
- 样子：更大的灰绿色守卫者（4×2 格），带伤疤。
- 生命 80；每个海底神殿生成 3 只。
- 行为：攻击附**挖掘疲劳III**（5 分钟）；激光更强。
- 掉落：海晶碎片 0–2、海晶砂砾 0–1、生鳕鱼（40%）、海绵（1，玩家击杀必掉）。

### 幻翼（Phantom）`phantom`
- 样子：灰蓝色翼龙状生物，夜晚飞向长时间不睡的玩家。
- 生命 20；玩家 3 天（72 小时=3 个游戏日）不睡觉时夜间生成。
- 行为：俯冲攻击（俯冲时无伤害，命中后离开）；白天燃烧。
- 掉落：幻翼膜 0–1（修复鞘翅用）。

### 史莱姆（Slime）`slime`
- 样子：绿色半透明果冻方块生物（1/2/4 格大小）。
- 生命：小型 1、中型 4、大型 16。
- 行为：跳跃移动；大型/中型分裂（4 只小一号）；只在沼泽（特定层位）与史莱姆区块生成。
- 掉落：黏液球 0–4，数量随体型增大（小型 0–1、中型 1、大型 2–4）。
