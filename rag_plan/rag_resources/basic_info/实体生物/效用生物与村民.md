# 效用生物与村民

> 目标版本：Java 版 1.20.4。村民与效用生物是村庄经济和玩家守护的核心。

## 村民（Villager）`villager`

### 基础信息
- 样子：绿袍村民，鼻子突出；职业不同衣着颜色不同（图书管理员白袍、铁匠黑围裙等）；皮肤颜色/职业由生物群系决定。
- 生命 20；生成于村庄（自然生成）或由僵尸村民治疗（虚弱药水+金苹果）。
- 行为：白天工作/闲逛，夜晚回床睡觉；躲雨；受铁傀儡保护；会被僵尸/卫道士攻击；**交易**是核心玩法。

### 职业与工作站（1.20.4）
| 职业 | 工作站方块 | 交易内容 |
|---|---|---|
| 农民 | 堆肥桶 | 作物→绿宝石，绿宝石→面包/西瓜/南瓜派 |
| 图书管理员 | 讲台 | 纸/书→绿宝石；出售附魔书 |
| 制图师 | 制图台 | 地图交易、探险家地图 |
| 牧师 | 酿造台 | 腐肉/金锭→绿宝石；出售红石/荧石/末影珍珠 |
| 盔甲匠 | 高炉 | 煤/铁→绿宝石；出售铁/钻石盔甲 |
| 武器匠 | 砂轮 | 出售剑/斧（铁→钻石） |
| 工具匠 | 锻造台 | 出售镐/斧/锹 |
| 屠夫 | 烟熏炉 | 肉类→绿宝石 |
| 渔夫 | 木桶 | 鱼→绿宝石 |
| 皮匠 | 炼药锅 | 皮革→绿宝石；出售皮革装备 |
| 石匠 | 切石机 | 黏土/石头→绿宝石；出售陶瓦/石英 |
| 傻子/失业 | 无 | 无交易 |

- 村民等级：新手→学徒→熟练→专家→大师，交易越多等级越高，解锁更多交易；大师级有独特交易。
- 繁殖：村民+村民（有床+食物面包/胡萝卜等）；村民会在有 3 张床以上时繁殖；与玩家交易提升好感。
- 僵尸村民（Zombie Villager）`zombie_villager`：生命 20，敌对；可用虚弱喷溅药水+金苹果治疗为村民（约 2–5 分钟），治愈后保留职业（被感染前的）。

### 特性细节
- 村民有物品栏（8 格）；会捡面包等食物。
- 被灾厄村民（掠夺者等）袭击时躲进屋；铁傀儡守护。
- 用 `/summon villager ~ ~ ~ {VillagerData:{profession:"minecraft:librarian", level:5, type:"minecraft:plains"}}` 可指定职业/等级/生物群系类型。

## 流浪商人（Wandering Trader）`wandering_trader`
- 样子：蓝色长袍白头巾商人，戴兜帽。
- 生命 20；随机出现于世界（每 20–30 分钟，停留 2–3 天）；带 2 只行商羊驼。
- 行为：会喝隐身药水；出售随机物品（珊瑚、热带鱼桶、黏液球、鹦鹉螺壳、海龟帽? 等稀有物品）；可被击杀（无掉落）。
- 交易：与村民相同界面，但货物随机。

## 铁傀儡（Iron Golem）`iron_golem`
- 样子：约 2.7 格高的铁灰人形，胸前爬有藤蔓。
- 生命 100；生成方式：村庄（村民 20+ 且 75% 村民工作过时，每 35 秒尝试一次）或玩家建造（4 个铁块 T 形+南瓜头）。
- 行为：
  - 保护村庄：主动攻击僵尸、骷髅、蜘蛛、史莱姆等敌对生物（**不主动攻击苦力怕**与恶魂）。
  - 中立：玩家攻击时反击（被激怒会一直追击）；玩家攻击村民也会被攻击。
  - 将玩家/村民抛起（攻击效果）；免疫溺水、摔落、火焰（不免疫岩浆? 免疫火焰伤害）。
  - 可被玩家用铁锭修复（右键）。
- 掉落：铁锭 3–5、罂粟 0–2（玩家击杀）。

## 雪傀儡（Snow Golem）`snow_golem`
- 样子：雪人（2 个雪块+南瓜头），行走留下雪迹。
- 生命 4；建造生成（雪块堆+南瓜头）。
- 行为：向敌对生物投掷雪球（击退，无伤害）；不会离开雪域（自动？）；在炎热生物群系/下界/熔岩附近会融化（受热伤害死亡）。
- 掉落：雪球 0–15。

## 悦灵（Allay）`allay`
- 样子：蓝色小精灵（约 0.35 格），发光的蓝眼睛，扇动翅膀。
- 生命 20；生成于掠夺者前哨站与林地府邸的笼子/柱子结构中。
- 行为：
  - 玩家给予物品后，悦灵会去拾取同类物品并带回给玩家（可指定方块位置放置）。
  - 跟随最近的玩家；可被玩家"信任"（喂食后更听话）。
  - **复制**：对播放音乐的唱片机给予任意唱片，悦灵会跳舞并产生新悦灵（需冷却）。
  - 不会受伤害（除非玩家攻击）；会捡拾掉落物。
- 掉落：无。

## 效用生物 NBT 要点
- 铁傀儡：`PlayerCreated:1b`（玩家建造标记）。
- 雪傀儡：无特殊。
- 悦灵：`DuplicationCooldown`（复制冷却）、`CanDuplicate`。
- 村民：`VillagerData`（type/profession/level）、`Inventory`、`Xp`。
