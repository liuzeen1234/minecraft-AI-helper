MC RAG 知识库候选数据源清单（可复制到苹果备忘录）

用途：为未来的 Minecraft RAG 功能收集候选素材，帮助 AI 理解原版特性、建筑和红石电路。
状态：这是资料采集清单，不代表当前 AI Builder 已实现或会自动加载 RAG。当前发布版没有知识库检索、资源释放或 `[KNOWLEDGE]` 标签处理；实施状态以 `RAG_PLAN.md` 为准。
目标 MC 版本：Java 版 1.20.4（与当前 Mod 运行版本一致）。

一、MC 基础信息文档（方块/实体/游戏机制/NBT）

1. 中文 Minecraft Wiki：zh.minecraft.wiki
作用：中文百科，可作为方块、物品、实体、游戏规则、NBT 和版本特性的核验来源。

2. 英文 Minecraft Wiki：en.minecraft.wiki
作用：英文原版维基，可用于补充红石与技术细节。

3. McFun 我的世界百科：https://www.mcshuo.com/encyclopedia
作用：结构化表格资料，可作为待人工核验的候选来源。

4. AstroWorld MC 技术文档站：https://astroworldmc.com
作用：红石底层机制、刻时序、活塞准连通等技术细节的候选来源。

二、建筑文档（简单建筑 + 带内外饰精美建筑）

1. BuildGuides：https://buildguides.net
作用：分层搭建、房间功能、内饰和材料清单等候选素材。

2. MinePilot：https://www.myminepilot.com/
作用：生存小屋、城堡、港口建筑等文字说明候选素材。

3. SchemCraft：https://schemcraft.com
作用：中世纪建筑和大型府邸的候选素材；使用前必须确认作者许可。

4. PlanetMinecraft：https://www.planetminecraft.com
作用：社区建筑作品与作者说明；使用前必须确认具体作品许可。

5. Shulkr：https://www.shulkr.com
作用：Litematic/Schem 预览与建筑资料的候选来源。

6. 9Minecraft：https://www.9minecraft.net
作用：建筑存档与介绍的候选来源；使用前必须核验来源和再分发许可。

三、红石文档（基础单元 + 复杂生电机器）

基础红石单元

1. AstroWorldMC 红石专题：https://redstone.astroworldmc.com/components
作用：红石元件的输入输出、延迟、方块状态和常见问题候选素材。

复杂红石/生电机器

1. RedenMC 红石伊甸园：https://redenmc.com/zh_cn
作用：机器原理、时序、适配版本和产量说明的候选来源。

2. RMC 红石团队文档：shturl.cc/8Diu6CLpDiZj
作用：活塞门、时序电路和组合逻辑机器的候选资料。

3. Technical Minecraft Wiki
作用：生电阵列、BUD 与版本专属机制的候选资料；必须逐项核验 1.20.4 适配性。

4. GitHub 搜索关键词：`minecraft redstone document`
作用：Markdown 红石机器文档的候选来源；必须核验许可与版本。

四、重要备注

1. 版本约束：未来入库文档统一标注 Java 版 1.20.4；不要将 1.20.1 或其他版本特有的红石和游戏机制当作 1.20.4 事实。
2. 版权提醒：网页内容仅可在符合来源许可和适用条款的前提下用于本地资料；不要未经授权大批量抓取或公开上传他人教程、结构文件或蓝图。
3. 当前 `rag_plan/rag_resources/` 仅为仓库中的离线候选素材，不会随 Mod 自动安装，也不会被当前 AI 检索。结构资源如需游戏内使用，应由用户手动复制到 `ai-helper/structures/nbts/` 或 `ai-helper/structures/litematic/` 并自行验证。
